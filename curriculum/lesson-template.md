# Lesson template

- **ID / title:**
- **Unit / level:** foundational, core, or advanced
- **Prerequisites:** conceptual and computational
- **Question:** one decision or mechanism this lesson resolves
- **Learning objectives:** 2–4 observable outcomes
- **Mini-lecture (15–20 min):** definitions, core equations, assumptions, interpretation
- **Mini-lab (20–40 min):** dataset/problem, baseline, one controlled variable, procedure
- **Diagnostics (~10 min):** plots/metrics, sanity checks, deliberately induced failure
- **Checkpoint:** explain why it works, when it fails, and what evidence supports conclusions
- **Artifacts:** code path, figures, results, environment, random seeds
- **Decision:** complete / review / skip / deepen; note why
- **Extensions:** optional, not required to advance

## Lab reporting minimum
Record dataset provenance or generating equation, train/validation/test partition (if relevant), parameter count, random seeds, hyperparameters, stopping criteria, hardware, wall time, and metrics. Compare against a simple baseline; avoid using test results to tune the model.
